## 🔧 故障排除

### 问题 1: 编译错误

**症状**: 找不到 Windows::Storage 等命名空间

**解决**:
1. 检查项目类型是否为 C++/CX（不是 C++/WinRT）
2. 确保引用了正确的 Windows SDK
3. 检查 pch.h 是否正确包含

### 问题 2: 无法连接到远程设备

**解决**:
1. 确认设备 IP: 192.168.3.67
2. 确认设备开发者模式已启用
3. 尝试 ping 192.168.3.67
4. 检查防火墙设置

### 问题 3: 部署失败

**解决**:
1. 在设备上卸载旧版本应用
2. 重启设备
3. 重新部署

### 问题 4: 应用崩溃

**解决**:
1. 检查 Package.appxmanifest 中的 codeGeneration 权限
2. 使用远程调试查看崩溃原因
3. 检查输出窗口的错误信息
